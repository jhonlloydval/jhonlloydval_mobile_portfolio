## 🚀 Featured Projects

### ⭐ Hakbang — College Journey Companion

> *Full-stack mobile platform built for Filipino senior high students navigating college decisions.*

<table>
<tr>
<td width="58%">

**Hakbang** aggregates **college discovery**, **scholarship matching**, an **AI counselor (Gabay)**, and **review center resources** into one unified app. Backed by a live Node.js API and a dedicated AI service — both deployed on Render.

Millions of Filipino students navigate college planning with zero structured guidance. Hakbang fills that gap with an always-available, intelligent, and accessible platform — bridging the divide between Metro Manila and provincial students.

**Stack:** `Flutter` `Dart` `Node.js` `REST API` `OpenStreetMap` `AI`

**Status:** 🟢 Live

</td>
